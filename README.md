# ISEE interactive demonstration

ISEE — Preview before you visit. An Autism & Me service.

This is a demonstration that runs entirely in the browser. The venues are made up. Nothing you enter is
sent anywhere, with one exception: if you use the Eircode and address search and press "Show the map and
front view", what you typed is sent to Google to find the map and street view. It is not the hosted ISEE
service.

The Eircode and address search lives in the `street/` folder. See [street/README.md](street/README.md).
